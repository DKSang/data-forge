# Book concept coverage plan

This is the working map for applying the important concepts in Joe Reis and Matt Housley, *Fundamentals of Data Engineering*, 1st ed. (O’Reilly Media, 2022), across Data Forge. It is a coverage plan, **not a claim that all references are finished**. Skill instructions and references are original explanations and decision aids: do not copy the local Markdown transcription, book passages, figures, or tables into this repository.

The book's local Markdown line numbers are useful for checking this copy but are not stable citations and may not match print pagination. Prefer chapter and section names below in published references. The book's maturity model and architecture principles are author frameworks, not universal standards; Chapter 11 and some appendix forecasts are explicitly time-bound or speculative. Verify current product, security, legal, network and pricing facts against current primary sources.

## Build and review sequence

References are authored and reviewed as independent increments, not generated in one batch. For each increment:

1. Read the cited book sections and existing Data Forge guidance; record concepts in original wording and identify which material is principle, author framework, example, or time-sensitive forecast.
2. Draft one reference with its intended skill owner, practical decision prompts, trade-offs, anti-patterns, and boundaries to avoid duplicating sibling references.
3. Independently check fidelity against the source, then check that the reference changes what a data engineer asks or decides. Fix any unsupported assertion or missing central idea before proceeding.
4. Update this map's status and links only after the reference exists and its checks pass. Keep the user involved in approving the scope and content between increments.
5. Test the relevant skill behavior with synthetic local/cloud scenarios. A keyword or mention-count check is not evidence of conceptual coverage.
