# Setup skills

Skills that orient work, retrieve project context, determine the next useful step, and route to Brain, Design, Build, or Operate specialists.

- [forge-de](forge-de/SKILL.md) — entry point for a new or continuing data-engineering initiative across local, on-prem, cloud, or hybrid environments.

The setup skill should remain a router, not a duplicate of Brain's project knowledge, Design's decision guidance, Deliver's implementation checks, or Operate's ongoing health/control practices.
