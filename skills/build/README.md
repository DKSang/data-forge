# Build skills

Skills that implement agreed, scoped data-engineering changes and verify them with proportionate tests.

- [forge-de-deliver](forge-de-deliver/SKILL.md) — implement and validate a local, on-prem, cloud, or hybrid data slice when explicitly requested.

Design-document approval, an implementation request, and authorization for remote effects are separate. Ongoing health and control maintenance hand off to [forge-de-operate](../operate/forge-de-operate/SKILL.md).
